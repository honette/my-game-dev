# Asset Management

## Asset Categories

- Party Characters（フィールド / 戦闘 / 立ち絵）
- Enemies
- Bosses
- NPCs
- Maps & Tilesets
- Battle Backgrounds
- Items & Icons
- UI
- VFX

## Asset Rule

ゲーム内で使用するアセットは、可能な限り一貫したアートディレクションで生成・管理する。

## Asset Record

各主要アセットについて以下を記録する。

- Asset ID
- Name
- Category
- Purpose
- Visual Description
- Animation States
- Reference
- Current Status

## Generated Asset Policy

AI生成アセットは、既存アセットとの整合性を確認してから採用する。
