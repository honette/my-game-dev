# Asset Management

## Asset Categories

- Player
- Enemies
- Bosses
- NPCs
- Environment
- Props
- Items
- UI
- VFX

## Asset Rule

ゲーム内で使用するアセットは、可能な限り一貫したアートディレクションで生成・管理する。

## Asset Record

各主要アセットについて以下を記録する。

- Asset ID
- Name
- Category
- Purpose
- Visual Description
- Animation States
- Reference
- Current Status

## Generated Asset Policy

AI生成アセットは、既存アセットとの整合性を確認してから採用する。
