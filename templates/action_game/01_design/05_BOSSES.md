# Boss Design

## Boss Philosophy

ボスはHPの多い敵ではない。
それまでに学習した戦闘原則を組み合わせ、新しい判断を要求する試験として設計する。

## Boss Template

- Name
- Theme
- Arena
- Phase Count
- Core Mechanic
- Attack Set
- Telegraphs
- Defensive Responses
- Punishment
- Recovery Windows
- Phase Transition
- Intended Player Learning
- Reward

## Initial Plan

6時間規模の場合、主要ボスは4〜6体程度を目安にする。
実際の数はプロトタイプ後に調整する。
